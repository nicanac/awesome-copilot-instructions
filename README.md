# Awesome Copilot Instructions

A curated collection of best-practice Copilot instructions and coding guidelines for a wide range of languages, frameworks, and development scenarios.

## 🚀 Features

- **Language-Specific Guidelines**: Comprehensive instructions for Java, Python, JavaScript, TypeScript, Go, C++, and more
- **Framework-Focused**: Specialized guidelines for React, Vue, Angular, Next.js, Spring Boot, Flutter, and popular frameworks
- **Best Practice Oriented**: Emphasis on SOLID, DRY, KISS, YAGNI, OWASP, DOP, FP, and DDD principles
- **Production Ready**: Guidelines tested and refined by senior developers
- **MIT Licensed**: Free to use and modify for any project

## 🎯 Quick Start

### 1. Find Your Stack
Browse the `rules-copilot-instructions/` directory to find instructions for your technology stack:

- **Web Development**: `nextjs-typescript-tailwind`, `react-typescript-nextjs`, `vue-3-nuxt-3-typescript`
- **Backend**: `python-fastapi`, `java-springboot-jpa`, `go-backend-scalability`
- **Mobile**: `android-jetpack-compose`, `flutter-development-guidelines`
- **Database**: `python-containerization`, `nextjs-supabase-todo-app`
- **Blockchain**: `solidity-foundry`, `solidity-react-blockchain-apps`
- **Game Development**: `unity-copilot-ai-c`, `dragonruby`

### 2. Copy Instructions
Navigate to your chosen directory and copy the `copilot-instructions.md` file to your project root or `.github/` directory.

### 3. Customize for Your Project
Modify the instructions to match your specific:
- Project requirements
- Team coding standards
- Technology versions
- Architecture patterns

## 🤝 Contributing

We welcome contributions! Here's how you can help:

### Adding New Instructions
1. Create a new directory under `rules-copilot-instructions/`
2. Follow the naming convention: `technology-framework-purpose`
3. Use the standard template structure (see existing files)
4. Include comprehensive guidelines and best practices

### Improving Existing Instructions
1. Fork the repository
2. Make your improvements
3. Test with real projects
4. Submit a pull request

### Template Structure
Each instruction file should include:
- **Overview**: Brief description of the technology stack
- **Development Principles**: Core principles and best practices
- **Technical Stack**: Versions, dependencies, and tools
- **Coding Standards**: Naming conventions, organization, patterns
- **Quality Assurance**: Testing, documentation, deployment
