# TypeScript Expo Jest Detox Copilot Instructions

## Key Principles
- Use TypeScript for type safety in React Native development
- Follow functional programming patterns; avoid class-based components  
- Implement proper testing with Jest and end-to-end testing with Detox
- Optimize performance and ensure accessibility compliance
- Use Expo's managed workflow for streamlined development

## TypeScript Guidelines  
- Use strict TypeScript configuration for mobile development
- Define proper types for component props and navigation parameters
- Leverage React Native-specific TypeScript types
- Use proper type definitions for Expo SDK modules
- Avoid `any` type; use proper type assertions

## React Native & Expo Best Practices
- Use Expo managed workflow for streamlined development
- Implement proper navigation with React Navigation
- Use Expo SDK modules for platform-specific functionality
- Follow React Native performance optimization patterns
- Ensure compatibility across iOS and Android platforms

## Testing Strategy
- Write unit tests with Jest for business logic
- Implement component testing with React Native Testing Library
- Use Detox for end-to-end testing across platforms
- Test accessibility features and keyboard navigation
- Mock Expo modules and native dependencies properly

## UI and Styling
- Use responsive design with Flexbox and useWindowDimensions
- Implement dark mode support with useColorScheme
- Follow React Native styling conventions
- Ensure accessibility with proper ARIA roles and props
- Use styled-components or similar for component styling

## Performance Optimization
- Minimize re-renders with React.memo and useMemo
- Use lazy loading and code splitting where appropriate
- Optimize images and assets for mobile platforms
- Implement proper state management with Context API or Redux
- Use React Native performance profiling tools

## Security and Data Management
- Use react-native-encrypted-storage for sensitive data
- Implement proper authentication flows
- Validate API responses with Zod or similar libraries
- Handle deep linking and universal links securely
- Follow Expo security best practices

## Error Handling and Debugging
- Implement global error boundaries
- Use Expo error reporting or Sentry for crash reporting
- Handle network errors and offline scenarios
- Provide proper error messages and fallback UI
- Use React Native debugging tools effectively
