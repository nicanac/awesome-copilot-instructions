# Next.js 14 Tailwind SEO Copilot Instructions

## Key Principles
- Use Next.js 14+ App Router for modern React applications
- Implement TypeScript for type safety and better developer experience
- Apply Tailwind CSS for utility-first styling and responsive design
- Optimize for SEO with Next.js metadata API
- Ensure accessibility compliance and performance optimization

## Next.js 14 Best Practices
- Use Server Components by default; Client Components only when needed
- Implement proper data fetching with `fetch` API and caching strategies
- Use the new `generateMetadata` function for dynamic SEO metadata
- Leverage streaming for better user experience
- Follow App Router directory structure and conventions

## TypeScript Guidelines
- Use strict TypeScript configuration
- Define proper types for props, components, and API responses
- Leverage TypeScript utility types (`Partial`, `Pick`, `Omit`, etc.)
- Use `const` assertions and proper type inference
- Implement error boundaries with proper typing

## Tailwind CSS Best Practices
- Use responsive design classes (`sm:`, `md:`, `lg:`, `xl:`)
- Follow mobile-first design principles
- Create custom utility classes when needed
- Use Tailwind's color palette and spacing system
- Implement dark mode support with `dark:` prefix

## SEO Optimization
- Use Next.js metadata API for dynamic meta tags
- Implement structured data (JSON-LD)
- Optimize Core Web Vitals (LCP, FID, CLS)
- Use semantic HTML elements
- Implement proper heading hierarchy (h1, h2, h3, etc.)

## Performance Optimization
- Optimize images with Next.js `Image` component
- Use dynamic imports for code splitting
- Implement proper caching strategies
- Minimize bundle size with tree shaking
- Use React Suspense for loading states

## Accessibility Guidelines
- Use semantic HTML elements appropriately
- Implement proper ARIA attributes
- Ensure keyboard navigation support
- Maintain sufficient color contrast ratios
- Provide alt text for images

## Code Organization
- Follow modular component architecture
- Separate business logic from UI components
- Use custom hooks for reusable logic
- Implement proper error handling
- Write meaningful component and function names
