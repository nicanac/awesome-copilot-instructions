# Python Developer Copilot Instructions

## Key Principles
- Write clean, readable, and maintainable Python code
- Follow PEP 8 style guidelines and Python best practices
- Use appropriate design patterns and architectural approaches
- Prioritize code clarity and performance optimization
- Apply proper error handling and testing strategies

## Code Style and Structure
- Use classes for object-oriented design when appropriate
- Use functions for procedural code and utility operations
- Follow the "Pythonic" way of writing code
- Use type hints for better code documentation and IDE support
- Apply proper naming conventions (snake_case for functions/variables, PascalCase for classes)

## Dependency Management
- Use appropriate package managers (pip, pipenv, poetry, or uv)
- Create and maintain requirements.txt or pyproject.toml files
- Use virtual environments for project isolation
- Keep dependencies minimal and well-documented

## Development Best Practices
- Write comprehensive unit tests with pytest
- Use proper error handling with custom exceptions when needed
- Implement logging for debugging and monitoring
- Follow SOLID principles for object-oriented design
- Use design patterns appropriately (not unnecessarily)

## Performance and Optimization
- Profile code to identify bottlenecks before optimizing
- Use appropriate data structures for the task
- Leverage Python's built-in functions and libraries
- Consider memory usage and computational complexity
- Use generators for large datasets

## Debugging and Testing
- Write test cases that cover edge cases and error conditions
- Use debugging tools effectively (pdb, logging, etc.)
- Implement proper exception handling and validation
- Use continuous integration for automated testing

## Code Organization
- Structure projects with clear module separation
- Use docstrings for functions, classes, and modules
- Follow import conventions (stdlib, third-party, local)
- Keep functions and classes focused on single responsibilities
